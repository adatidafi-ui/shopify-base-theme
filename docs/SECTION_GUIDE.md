# Section Guide Reference

## Available Sections

### Announcement Bar
**Purpose:** Sticky top bar for promotions, shipping info, urgency

**Settings:**
- Enable/disable
- Text (emoji-friendly)
- Background/text colors
- Dismissible toggle

### Hero
**Purpose:** Full-width hero with headline, CTA, and imagery

**4 Layout Variants:**
1. Image with centered text
2. Image left, text right
3. Gradient background (no image)
4. Text only

**Settings:** Layout, image, heading, subheading, CTA, text color, overlay opacity, gradient colors

### Trust Badges
**Purpose:** 3-4 trust signals (shipping, guarantee, social proof)

**Blocks:** Icon, title, description

### Featured Product
**Purpose:** Highlight single product with 60/40 image/info layout

**Settings:** Product selector, benefits 1-3

**Auto-pulls:** Title, description, image, price, rating

### Problem/Solution
**Purpose:** 2-section storytelling (pain point → resolution)

**Settings:** Problem/solution titles, descriptions, images

### Benefits
**Purpose:** Feature list with icons and descriptions

**2 Layouts:** 4-column grid or alternating image/text

**Blocks:** Icon, title, description, image (optional)

### Testimonials
**Purpose:** Social proof via customer reviews

**3 Layouts:** 3-column grid, carousel, single slide

**Blocks:** Quote, author, role, avatar

### FAQ
**Purpose:** Accordion section for common questions

**Blocks:** Question, answer

**Features:** Expand/collapse animation, keyboard accessible

### Newsletter
**Purpose:** Email signup CTA with gradient background

**Settings:** Heading, description, button text, background/text colors, privacy text

### Footer
**Purpose:** Links, newsletter, social, payment info

**4 Columns:**
1. Shop
2. Company
3. Support
4. Newsletter (if enabled)

**Bottom bar:** Copyright text, payment icons

## Default Homepage Structure

1. Announcement Bar
2. Header
3. Hero
4. Trust Badges
5. Featured Product
6. Problem/Solution
7. Testimonials
8. Benefits
9. FAQ
10. Newsletter
11. Footer

## Adding Sections

**Homepage:** Click "+" in Theme Editor → select section → configure

**Product page:** Fixed structure (cannot add sections via UI)

## Hiding/Reordering Sections

- **Hide:** Delete from Theme Editor
- **Reorder:** Drag/drop section handle in left sidebar

## Adding/Editing Blocks

Sections with blocks (repeatable items):

1. Select section
2. Scroll to "Blocks"
3. Click "+" to add
4. Fill in content
5. Drag to reorder or delete

**Example: Adding a testimonial**
1. Testimonials → Blocks → "+"
2. Fill in: Quote, Author, Role, Avatar
3. New testimonial appears automatically
