# Launch Checklist

## Content & Configuration

- [ ] Logo uploaded and sized correctly
- [ ] Favicon set (192x192px)
- [ ] Brand colors configured (primary, accent)
- [ ] Fonts selected (heading and body)
- [ ] Hero section: image, headline, CTA configured
- [ ] Trust badges: all 3-4 with real, accurate content
- [ ] Featured product: selected and displays correctly
- [ ] Problem/solution: copy and images match product
- [ ] Benefits: 4 real benefits listed
- [ ] Testimonials: at least 3 real customer reviews
- [ ] FAQ: 5+ real FAQs answered
- [ ] Newsletter: signup text is clear
- [ ] Footer: copyright year correct, all links working
- [ ] Product page:
  - [ ] At least 3 product images
  - [ ] Detailed description
  - [ ] Clear pricing
  - [ ] Variants configured (size, color, etc.)
  - [ ] All options named and priced

## Store Setup

- [ ] Store name correct
- [ ] Custom domain configured (not myshopify.com)
- [ ] Shipping rates configured
- [ ] Tax settings configured
- [ ] Payment gateway connected (Stripe, PayPal, etc.)
- [ ] Policies linked:
  - [ ] Privacy Policy
  - [ ] Terms of Service
  - [ ] Returns Policy
  - [ ] Shipping Policy
- [ ] Contact page/form working
- [ ] Transactional emails configured

## Mobile & UX

- [ ] Mobile responsive on iPhone SE, 12 Pro Max, Android
- [ ] Portrait and landscape orientations work
- [ ] Touch targets all >= 44px height
- [ ] Forms work on mobile
- [ ] Images load quickly
- [ ] Cart drawer opens/closes smoothly
- [ ] Sticky cart appears when scrolled past product
- [ ] Mobile menu works, all links accessible
- [ ] Font sizes readable without zoom

## Performance

- [ ] Lighthouse Mobile: 90+ score
- [ ] Lighthouse Desktop: 95+ score
- [ ] Core Web Vitals: all green
  - [ ] LCP: <2.5s
  - [ ] FID: <100ms
  - [ ] CLS: <0.1
- [ ] Images optimized (compressed before upload)
- [ ] Inline critical styles loaded
- [ ] No blocking scripts in <head>
- [ ] Fonts self-hosted via Shopify
- [ ] Third-party apps minimized

## Accessibility

- [ ] Heading hierarchy proper (H1 -> H2 -> H3)
- [ ] All images have descriptive alt attributes
- [ ] Color contrast meets WCAG AA (4.5:1 normal, 3:1 large)
- [ ] Tab through all interactive elements
- [ ] Visible focus rings on buttons/links
- [ ] All inputs have associated labels
- [ ] Screen reader test (NVDA or VoiceOver)
  - [ ] Page structure makes sense
  - [ ] Images have alt text
  - [ ] Form labels announce correctly
  - [ ] Buttons/links announce as interactive

## Conversion Optimization

- [ ] Product page flow natural (image -> info -> CTA -> trust -> details)
- [ ] Primary CTA stands out (high contrast, large)
- [ ] Price clearly visible
- [ ] Compare-at price shows savings
- [ ] Trust elements visible (shipping, returns, guarantee)
- [ ] Real testimonials, not generic
- [ ] Urgency only if factually accurate
- [ ] Checkout flow minimal steps
- [ ] Express checkout available
- [ ] Cart has clear order summary

## SEO

- [ ] Homepage title: short, keyword-relevant (50-60 chars)
- [ ] Homepage meta description: clear CTA (150-160 chars)
- [ ] Product title: product name + key attribute (50-60 chars)
- [ ] Product description: benefits, keywords, 150+ words
- [ ] Images: descriptive alt text
- [ ] URLs: clean, descriptive
- [ ] Heading tags used correctly
- [ ] Internal links to relevant pages
- [ ] Robots.txt: allow (default)
- [ ] Sitemap: auto-generated at /sitemap.xml

## Integrations

- [ ] Email marketing: Mailchimp, Klaviyo, or Shopify Email
- [ ] Analytics: Google Analytics or similar
- [ ] Conversion tracking: Facebook Pixel, Google Ads
- [ ] Review app: Loox, Judge.me, etc. (if using)
- [ ] Chat support: Gorgias, Zendesk, etc. (if using)

## Legal

- [ ] Privacy Policy written, linked in footer
- [ ] Terms of Service written, linked in footer
- [ ] Returns Policy clear, reasonable
- [ ] Shipping Policy clear, includes timeframes
- [ ] GDPR (if EU): consent banner, GDPR-compliant policy
- [ ] CCPA (if US): privacy disclosures

## Testing

- [ ] Add to cart works (desktop + mobile)
- [ ] Complete checkout flow
- [ ] Newsletter signup sends email
- [ ] All internal/external links working
- [ ] 404 page shows on non-existent page
- [ ] Search page displays results
- [ ] Filters work (if enabled)
- [ ] Pagination works
- [ ] Mobile menu opens/closes
- [ ] Cart drawer opens/closes
- [ ] Product options update correctly
- [ ] Image zoom works (desktop), swipe works (mobile)
- [ ] Testimonials carousel displays correctly
- [ ] FAQ accordion expands/collapses smoothly

## Final Review

- [ ] Site feels like your brand
- [ ] Copy quality: no typos, professional tone
- [ ] Images professional, high-quality
- [ ] Colors, fonts, spacing consistent throughout
- [ ] Loading feels fast
- [ ] Mobile friendly, thumb-friendly, no horizontal scroll
- [ ] Compares well to competitors
- [ ] Tested on 3+ real devices
- [ ] Tested on Chrome, Safari, Firefox (latest)

## Go Live

- [ ] Theme backed up to GitHub
- [ ] Domain pointed to Shopify store
- [ ] SSL certificate enabled
- [ ] Analytics tracking deployed
- [ ] Announcement ready (email, social, etc.)
- [ ] Monitoring set up for downtime/conversion drop

## Post-Launch

- [ ] Monitor analytics first 24-48 hours
- [ ] Check emails deliver correctly
- [ ] Reach out to first customers
- [ ] A/B test CTA colors, headlines, layouts
- [ ] Iterate based on data
